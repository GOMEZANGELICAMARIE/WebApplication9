# WebApplication9 - ASP.NET Core MVC Portfolio

An MVC web application serving as a modern project portfolio built with C# and ASP.NET Core.

## Features
- **Table of Contents**: Displays an organized list of projects with thumbnails and GitHub repository links.
- **Detail Page**: Comprehensive information view for each individual project.
- **Comment System**: Interactive comment section on every project detail page.
- **Authentication**: Session-backed login access control.
